# Самопроверка перед сдачей

Пройти по пунктам, каждый «нет» - исправить, а не отметить.

1. Все 7 разделов чек-листа и все подпункты есть в артефакте.
2. Каждая цифра имеет источник: URL, SQL с датой или пометку «допущение».
3. Все конкуренты из `01-landscape.md` и списков «новые игроки» от агентов попали в
   таблицу (или помечены «отсеян, почему»).
4. У каждого живого конкурента есть цена на типовых профилях и скриншот тарифов (или
   пометка, почему нет).
5. Матрица функций без пустых ячеек: есть / частично / нет / не подтверждено. Каждая функция,
   которая есть у 3+ конкурентов (частотный счёт по `text/*.txt` и меню тарифов), стоит в
   матрице и, если у нас её нет, - в разрывах и скоупе.
6. Режим «существующий»: у каждого раздела есть «у нас сейчас», разрывы посчитаны
   (сколько клиентов задевает, сколько стоит закрыть).
7. Голос клиента - цитаты с датой и чатом, частоты болей с числами.
8. Симуляции: входы таблицей, распределения из данных, вывод - решение.
9. Решения: у каждого «требует действия» - кто и до какой даты.
10. Текст: дефис вместо длинного тире, цифры цифрами, без воды, первая фраза несёт мысль.
11. Посылки из постановки (числа владельца, из старых отчётов) пересняты своим запросом;
    расхождения названы.
12. Ничего не отправлено в чужие чаты, нигде не зарегистрировались.
